# Habits 💪

A simple weekly tracker for getting back on track and building strong habits.

## Current focus: 6-week build

- **Started:** Week of Sun 28 Jun 2026 (back home in Israel)
- **Target:** Tue 11 Aug 2026 — next trip ✈️
- **Goal:** Six solid weeks. Rebuild the routine, lock in the anchor habits, arrive at the trip feeling strong.
- **Mode:** Small cut — back to lifting, usual training split, hitting protein, eating at home.

## The anchor habits

These are the daily non-negotiables we're rebuilding. Each week's log tracks them.

1. **Protein** — hit the daily protein target (the one that matters most)
2. **Movement** — some intentional activity
3. **Sleep** — wind down, decent night
4. **No-track days are slip days, not failures** — log it honestly and move on

## How it works

- One file per week in this folder: `YYYY-week-of-MM-DD.md`
- Each day gets a quick checklist + a one-line note
- Travel / off days are expected — the win is logging them, not being perfect
- At week's end, jot a 2-line review and start the next week's file
